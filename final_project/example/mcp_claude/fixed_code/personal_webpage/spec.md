# Personal Website Template Spec

## Task
Create a polished static personal website template for a fictional person named Avery Hart.

Use plain HTML files with inline CSS and JavaScript only if needed. Do not use a framework, build step, backend, or external runtime dependency.

## Pages
Build three pages:
- `index.html` - landing page
- `blog.html` - blog landing page
- `resume.html` - resume page

All pages should share the same visual system, top navigation, and footer.

## Visual Direction
- Dark charcoal background with light, readable text.
- Compact academic/personal website style.
- Polished cards or panels with subtle borders.
- Consistent spacing, typography, and link treatments.
- The site should look complete and usable in a 1280x720 viewport.

## Navigation
Every page should include a top navigation bar with:
- Avery Hart or the site name linking to `index.html`
- Blog Posts linking to `blog.html`
- Resume linking to `resume.html`

The navigation should be visible, readable, and usable from each page.

## Landing Page
The landing page should include:
- A left profile or identity panel for Avery Hart.
- Name: Avery Hart.
- A short role summary mentioning robotics and computer vision.
- Contact or profile rows for Email, ORCID, GitHub, and LinkedIn.
- A main content area with a short welcome, bio, and selected interests.

The profile rows should include compact icon-like markers or abbreviations next to clear text labels.

## Blog Page
The blog page should include:
- Shared navigation and footer.
- A clear page title.
- Several realistic post previews with titles and summaries.
- A layout that keeps the post list readable and usable in the viewport.

## Resume Page
The resume page should include:
- Shared navigation and footer.
- Resume-style sections for Experience, Education, and Projects.
- Compact entries with readable titles, bullets, or short descriptions.
- A layout that keeps the resume readable and usable in the viewport.

## Acceptance Criteria
- `index.html`, `blog.html`, and `resume.html` exist.
- The pages share a coherent dark personal-site design.
- Navigation links are present and usable on every page.
- Contact/profile rows on the landing page are visually understandable.
- Blog and resume pages appear complete.
- Important content remains visible and readable.
- The site fits cleanly in a 1280x720 viewport.
