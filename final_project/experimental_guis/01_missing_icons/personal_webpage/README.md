# Personal Webpage

## What It Is
A small personal website template for Avery Hart, a fictional robotics and computer vision engineer. The site has a home page, blog page, and resume page. The layout is inspired by an academic personal site with a dark theme, top navigation, profile sidebar, and simple content panels.

## How to Run
- Option 1: Open `index.html` directly in any modern browser
- Option 2: Serve locally with `npx serve .` and navigate to `http://localhost:3000`

No installation or build step required.

## Pages
- `index.html`: landing page with profile summary and contact links
- `blog.html`: blog landing page with several post previews
- `resume.html`: compact resume page with experience, education, and projects

## Notes
The pages share inline CSS and are designed as a compact static template for review in a 1280x720 viewport.
